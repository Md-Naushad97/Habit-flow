## 📌 About The Project

Habit Flow is a modern habit tracking website that helps users create, manage, and track their daily habits and tasks.

The main goal of this project is to make habit tracking simple, interactive, and visually engaging. Users can mark their habits as completed, monitor their progress, and understand their consistency through statistics and charts.

---

## ✨ Features

### 📋 Habit Management
- Add new habits and tasks
- View all created habits
- Mark habits as completed or incomplete
- Edit existing habits
- Delete habits

### 📊 Progress Tracking
- Track daily habit completion
- Calculate completion percentage
- View overall progress
- Track habit consistency
- Display progress statistics

### 📅 Time-Based Tracking
- Daily habit tracking
- Weekly progress
- Monthly progress
- Yearly progress

### 📈 Charts & Statistics
- Visual progress charts
- Daily completion statistics
- Monthly progress overview
- Habit completion percentage
- Progress and consistency information

### 🎯 User Experience
- Clean and modern interface
- Responsive design
- Smooth interactions
- Easy-to-use dashboard
- Professional college-project UI

### 💾 Data Storage
- Habit data can be stored locally
- Progress remains available after refreshing the page
